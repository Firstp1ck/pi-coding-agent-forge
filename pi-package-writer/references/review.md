# Reviewing fiction

Start with the author's intended reader effect and requested scope. A critique should make a draft easier to improve, not replace the author's taste with the reviewer's favorite style.

## Reading passes

1. Read the actual requested text, not only its outline. State any unread range.
2. Record reader reactions at specific passages: curiosity, confusion, tension, attachment, disbelief, or relief.
3. Diagnose likely causes using textual evidence. Separate a contradiction from a possible ambiguity and a taste preference.
4. Check character knowledge, chronology, object ownership, injuries, promises/payoffs, and viewpoint access against cited project evidence.
5. Check the chosen medium. Prose needs controlled viewpoint and rhythm; manga needs drawable moments and readable dialogue; serial fiction needs installment payoff.
6. Prioritize structural and causal problems before sentence polish. Preserve passages that already work.

## Finding format

- Location or short quoted passage.
- Observed issue and its effect on the reader.
- Relevant canon or craft constraint.
- Suggested repair and its trade-off.
- Confidence, including unresolved evidence.

Use severity only when meaningful. An impossible timeline can break the story. A preference for shorter sentences is not automatically a defect.

## Revision passes

Revise the approved scope to a new file. Check that the revision keeps the agreed facts, motives, POV, tense, and voice. If repairing one scene changes later events, identify the dependent passages instead of silently rewriting the whole book.

A simulated reader is a model-generated perspective, not evidence of real audience reception. Avoid claims that a story is objectively publishable or guaranteed to sell.
