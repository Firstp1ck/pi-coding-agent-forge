# Style and voice

## When to use

Use for changing tone, comparing voices, building a reusable style profile, or revising prose that lost the author's voice.

## Inputs and assumptions

Identify the desired reader effect, format, narrator, audience, language, and any author-provided or authorized samples. Style references are not sources of plot facts.

## Portable workflow

1. Read [style choices](../../references/styles.md) and the project's existing profile.
2. Translate labels into choices about viewpoint, distance, rhythm, vocabulary, imagery, dialogue, and emotional expression.
3. For a blend, specify where each effect leads. Epic stakes need not imply ornate narration.
4. Produce a short original calibration sample. If needed, compare two versions that differ in technique, not just adjective density.
5. Extract a concise profile from the author's chosen version. Preserve scene-specific exceptions.
6. For revisions, keep facts and intent fixed while changing expression. Identify changes that would require author approval.

## Safety and side effects

Do not copy distinctive passages from reference works or infer authorization to reuse supplied material beyond the task. Ask before replacing an established voice profile. Do not apply blanket cleanup rules that erase deliberate style.

## Scripts, references, and dependencies

No scripts. [The project workflow](../../references/project-workflow.md) defines approval and saving conventions.

## Verification

Check the result against the actual requested reader effect and samples. Confirm that canon did not change as a side effect of stylistic revision.

## Pi adapter

Use `/writer style --style "emotional, restrained" --brief "Compare two voices for the reunion scene"`.
