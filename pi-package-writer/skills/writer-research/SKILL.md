# Research for fiction

## When to use

Use when factual uncertainty affects a scene's plausibility or the author requests references for a setting or occupation.

## Inputs and assumptions

Identify the bounded factual question, period, location, required accuracy, and whether the work is historical, contemporary, or deliberately alternate-world fiction.

## Portable workflow

1. Separate the factual question from the manuscript's private plot and character details.
2. Check existing author-provided references before searching again.
3. If suitable research tools are available and authorized, search with a minimal factual query. Prefer primary or specialist sources for consequential details.
4. Record sources, dates when relevant, conflicting evidence, and uncertainty.
5. Explain the practical consequence for the scene without dumping unrelated background into the prose.
6. Mark departures from real-world facts as deliberate inventions only after author approval.
7. Save concise research notes only when requested, using [the project workflow](../../references/project-workflow.md).

## Safety and side effects

Never upload manuscript passages or private notes to search services without explicit authorization. Do not fabricate citations. If research tools are unavailable, label tentative knowledge and propose what needs checking.

## Scripts, references, and dependencies

No bundled browser, scraper, or API credentials. External research depends on the host's available tools and author approval.

## Verification

Check that factual claims have appropriate evidence, uncertain details remain labeled, and fictional changes are not presented as real history.

## Pi adapter

Use `/writer research --brief "Check how a nineteenth-century lighthouse keeper would receive supplies"`. The package does not install a search extension or contact external services itself.
